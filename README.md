# 📣 Previsão de Demanda

> Previsão de demanda de produtos para campanhas com ML. Antecipa picos, evita rupturas e otimiza estoque promocional por SKU e região.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/previsao-demanda-campanha/

[![Vertical](https://img.shields.io/badge/Vertical-Marketing-blue)]() [![IA](https://img.shields.io/badge/IA-ML-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]()

## 📊 Resultados-chave (KPIs)
**6.2%** MAPE · **-31%** Ruptura · **2.4M** SKUs · **91%** Acerto pico

## 🧠 Tecnologias de IA
ML · Time Series · Demand Forecasting

## ✨ O que faz
- Previsão por SKU e região
- Eventos brasileiros (Black Friday)
- Detecção de picos
- Otimização de estoque promo

## 🗄️ Fonte de dados real
[Vendas + sazonalidade](https://www.gov.br/mdic)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Vendas + sazonalidade
2. **Processamento com IA** — ML · Time Series · Demand Forecasting
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
